# vex-3773c-drivetrain-simulator
For the VEX robotics team 3773C, I designed a simulator to simulate the motion of our robot's drivetrain using differential drive kinematics. I'm continuing to improve on this code and add adjustments.

The simulator won us the Innovate Award at the Pemibaker VEX Robotics Tournament at Plymouth Regional High School in Plymouth, NH, as well as at the NH/VT 2026 VEX V5 Push Back Blended State Championship. We also won the Judges Award at the 2026 Bow Bot Bout thanks in part to it!
